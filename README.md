# seer-unity-assets
赛尔号Unity端静态资源节选，主要包含道具图标、精灵头像/全身图、Config数据等，每半小时检查一次更新。</br>
详见 [data-update-workflows](https://github.com/SeerAPI/data-update-workflows)
